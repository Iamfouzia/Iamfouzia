## 🚀 Featured Projects

### 🩺 Medreport AI
A medical report analysis dashboard that parses lab results and runs a RAG pipeline over reference ranges using FAISS, flagging abnormal blood parameters by severity. Built with Python, Streamlit, and Groq LLaMA 3.1.

### ChestScan AI
Chest X-ray analysis tool that generates automated radiology reports with confidence scoring, exportable as PDF, powered by the Groq LLaMA Vision API and a React frontend.

### 🧑‍💼 HireIQ — AI Talent Screener
Resume screening system that ranks candidates against job requirements using a RAG pipeline, a knowledge graph, and FAISS vector search built to cut through generic keyword matching.

### 💬 SafeSpace — AI Therapist
A mental health support chatbot with real-time crisis detection and automated emergency alerts, built on LangChain, Groq LLaMA, and FastAPI, served through Streamlit.

### 🧠 MindEase — AI Mental Health Chatbot
CBT-informed chatbot with real-time emotion detection and multilingual support, built with Flask and Hugging Face Transformers.

### 🧬 Parkinson's Disease Prediction
Random Forest classifier predicting Parkinson's disease from voice features, reaching 92% accuracy through full EDA, cross-validation, and GridSearchCV tuning.

### 🛍️ AI Fashion Sales Assistant
A shopping assistant chatbot handling product recommendations and order tracking, built with LangChain and OpenAI on a full-stack JavaScript backend.

### 🏫 E-Classroom Hub
Django-based classroom management system covering assignments, grading, and messaging between students and teachers.

### 🛒 Ministore
An online storefront with cart, checkout, and an admin panel for managing products and orders.

## Featured Projects

### Medreport AI
AI-powered medical report analysis dashboard built with Python, Streamlit, and Groq LLaMA 3.1. Features a RAG pipeline with FAISS vector search, blood parameter visualization, and severity assessment.

### ChestScan AI
AI-powered chest X-ray analysis tool built with React and the Groq LLaMA Vision API. Generates automated radiology reports with confidence scoring and PDF export.

### HireIQ — AI Talent Screener
AI-powered resume screening system using a RAG pipeline, Knowledge Graph, and FAISS vector search for intelligent candidate ranking, scoring, and shortlisting.

### SafeSpace — AI Therapist Chatbot
AI mental health therapist built with LangChain, Groq LLaMA, FastAPI, and Streamlit. Features crisis detection, emergency alerts, and empathetic CBT-based conversations.

### MindEase — AI Mental Health Chatbot
AI-powered mental health chatbot built with Flask and Hugging Face. Features real-time emotion detection and multilingual support.

### AI Voice Cloning
AI-based voice cloning system using text-to-speech models for realistic voice synthesis.

### Parkinson's Disease Prediction
Machine learning model to predict Parkinson's disease from voice features using Random Forest, achieving 92% accuracy through cross-validation and hyperparameter tuning.

### AI Fashion Sales Assistant
Full-stack chatbot with LangChain and OpenAI integration for product recommendations, order tracking, and conversational shopping.

### E-Classroom Hub
Django-based online classroom management system with assignment uploads, marks management, and messaging between students and teachers.

### Ministore
Full-featured online shopping website with cart, checkout, and an admin panel for managing products and orders.
